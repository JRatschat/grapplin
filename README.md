# Grapplin

Grapplin is a two-player climbing and shedding game where matching combinations grant special actions and jokers reverse rank order.

👉 View the game on BoardGameGeek:  
https://boardgamegeek.com/boardgame/460576/grapplin

Designer Diary: https://boardgamegeek.com/blog/16873/blogpost/181504/first-time-designer-notes-on-grapplin

## Repository Contents

This repository contains:
- The official **rules** (PDF/LaTeX source)
- **Assets and materials** for playing the game in real life and online

Play Grapplin online: https://virtualtabletop.io/game/grapplin
